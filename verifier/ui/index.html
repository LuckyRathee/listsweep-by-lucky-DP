This server is protected by API keys but has no user accounts, so nobody can sign in to this page.

If you own this server, add these two lines to its .env file and restart it:

EMAIL_VERIFIER_ADMIN_EMAIL=you@company.com
EMAIL_VERIFIER_ADMIN_PASSWORD=choose-a-strong-password

The first admin account is created from them on startup, and you can change the password from the Account page after signing in. API keys keep working unchanged for agents and scripts.
